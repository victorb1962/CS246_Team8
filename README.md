Course Outcomes
1. Demonstrate knowledge of the principles and practices of good object-oriented design.
2. Demonstrate knowledge of the syntax and semantics of the Java programming language.
3. Identify common software design patterns and explain how they can be applied in real-world problems.
4. Independently find and evaluate technical knowledge in order to develop solutions to challenging software development problems.
5. Demonstrate skill with the fundamentals of collaborative software development including source code version control.
